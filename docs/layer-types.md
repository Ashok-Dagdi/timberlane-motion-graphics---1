# Layer types — field reference

Generated by `node tools/sample-json.mjs` from `src/layers/engine-schema.js`,
the same table the editor builds its inspector from, so it cannot drift.

Rules that apply to every layer:

| key | meaning |
|---|---|
| `id` | unique string; everything else is optional |
| `type` | one of the types below |
| `in` | first second the layer exists |
| `dur` | how long it exists (`in + dur` = last frame) |
| `name` | label in the editor's layer list |
| `t` | placement: `x`, `y` are the box centre in canvas px, `w`/`h` the box, `r` corner radius, `rot` degrees, `anchorX/Y` to move the pivot, `z` paint offset, `parallax` camera drag 0–1 |
| `anim` | behaviour: `enter`, `exit`, `dur`, `ease`, `stagger`, `delay` |
| `props` | the type-specific fields below |

# Scene JSON — field reference

A scene is `{ name, fps, meta:{width,height,duration,title}, theme, assets, camera, beats, layers[] }`.
Every layer: `id, name, type, in, dur, hidden, locked, blend, parallax, t{}, anim{}, props{}` —
`t` = where it is, `anim` = how it arrives and leaves, `props` = what it draws.
